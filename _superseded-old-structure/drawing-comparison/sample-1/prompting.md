## 2026-09-15 · supplied PDFs found to be corrupted, repaired
Both files as supplied failed to open as PDF (`missing %PDF- header`). Inspection showed each file is a raw HTTP `multipart/form-data` body — a boundary line, `Content-Disposition`/`Content-Type` headers, then the real PDF bytes, then a closing boundary — consistent with a DocuSign envelope download saved without stripping the multipart wrapper. Repaired by extracting the byte span from the first `%PDF-` to the line containing the final `%%EOF` in each file. Repaired files verified as valid PDF 1.5 (`file` command; opened and read without error) and copied into `documents/source/` and `documents/supporting/`. Digests of the repaired files recorded in `file-index.md`.
