## D-260374-11-LEGEND2 — LEGEND SHEET (REV. B; 2 of 13)

Legend sheet 2: instrument identification grammar (ISA-style).

### CODING OF IDENTIFICATION LETTERS
First letter = measured / initiating variable; succeeding letters = readout / output function.
Succeeding-letter column read: SWITCH (13), TRANSMIT (14), TRANSMITTER (15),
INDICATE (16), CONTROL (17), RELAY/FILTER/FEEDBACK (18), … ; "SAFETY VALVE" appears as a
function entry (line 13/14 region). First-letter column entries include P (pressure),
T (temperature), F (flow), L (level), A (analysis), W (well/wind?), Y (state/relay),
Z (position/transition).

### TYPICAL IDENTIFIERS FOR P&ID'S (as printed)
- PSV = PRESSURE SAFETY RELIEF VALVE
- PCV = PRESSURE CONTROL VALVE
- FCV = FLOW CONTROL VALVE
- LCV = LEVEL CONTROL VALVE
- TV  = TEMPERATURE CONTROL VALVE
- SDV = SHUTDOWN VALVE
- SOV = SOLENOID VALVE
- FV  = FLOW VALVE
- HV  = HAND VALVE
- XV  = ON-OFF VALVE
- PSH / PSL = PRESSURE SWITCH HIGH / LOW
- (plus TI, TC, PI, PT, LI, LT, FI, FT, AI, AT, Y, ZS/ZSC/ZSO family entries)
Note: KV (used on -011) is NOT in this list — see detection §7.

### INSTRUMENT LOCATION NUMBERS / SEQUENCE OF FUNCTION NUMBERS
Loop-number tables (area/sequence coding); read at overview level, not required for BOM.

### TYPICAL INSTRUMENT SYMBOLS
Bubbles: field-mounted circle; shared control/display D-cube; computer function hexagon;
line styles: pneumatic signal (dashed), electric signal (dotted), software/data (double
dashed); instrument line symbols.
