## D-260374-11-LEGEND1 — LEGEND SHEET (REV. B, "3 of 13" stamp area; ISSUED MAY 29 2026 FOR APPROVAL)

Legend sheet 1 of 2. Defines line types, flags/abbreviations, P&ID symbols, service codes,
line-number format, specialty-item numbers, and the equipment-number grammar.

### TYPICAL EQUIPMENT NUMBER (tag grammar: EQUIPMENT IDENTIFIER + ITEM NUMBER, e.g. E-001)

- B = BOILER
- C = COMPRESSOR, FAN, BLOWER, ETC.
- D = DRIVER (TURBINE, MOTOR, ETC.)
- E = HEAT EXCHANGER
- F = FILTER
- FS = FLARE STACK
- G = GENERATOR
- H = HEATER, FURNACE, ETC.
- K = COOLING TOWER
- L = ELEVATOR, CONVEYOR, ETC.
- M = CRUSHING & GRINDING
- P = PUMP
- R = REACTOR
- S = WAG SKID
- T = ATMOSPHERE TANK
- U = PACKAGED UNIT
- V = PRESSURE VESSEL
- W = WEIGHING DEVICE, SCALE
- X = MISCELLANEOUS
(Note: no CA or DR entry — those prefixes used on -011 are project-specific; see detection §7.)

### TYPICAL SPECIALTY ITEM NUMBER
Format: SP-001 (SPECIALTY ITEM TYPE + ITEM NUMBER). Specialty type letters read include
BR = BRANCH, E = EXPANSION JOINT, FI = FLARE INJECTOR, H = HOSE, HC = HOSE CONNECTION,
M = METER ORIFICE, PI = PIPE CAP, PR = PIPE REINFORCEMENT, RT = REDUCER TEE (partial list,
some rows UNSURE at crop edge).

### TYPICAL LINE NUMBER
Format: 6"-PO-1001-A3-1.5"H-EL → LINE SIZE / SERVICE CODE / LINE NUMBER / SPEC /
INSULATION OR TRACING / ELEVATION.

### PIPING SYSTEM SPECIFICATIONS

(ANSI flange class table; not needed for BOM values).

### SYMBOLS

plug, "SAFETY VALVE" symbol), vessel symbols (desiccant, flame arrestor, chemical seal,

nozzle, expansion joint, special item), reducers, expansion loops, drain/slope arrows,
vent-atmosphere and vent-to-flare symbols.
