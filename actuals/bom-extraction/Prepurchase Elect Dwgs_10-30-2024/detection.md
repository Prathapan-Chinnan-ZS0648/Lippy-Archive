# Detection

Document quirks and edge cases detected while building the twin and reading this
document, ahead of extraction. Recorded here per-run; anything that recurs across
independent samples is a candidate for `skills/bom-extraction/patternLog.md` (see
`bootstrap.md` §8.2, the promotion bar).

| Quirk | Where observed | Handling |
|---|---|---|
| Different drawing type than the skill's first sample | This document is a set of electrical one-line diagrams, elevations, and a physical layout plan for a generator/switchgear/transformer prepurchase package — not a P&ID. | `skills/bom-extraction/skill.md` Module 3 previously had only one domain-guidance row (P&ID). Its EQUIPMENT/SAFETY-RELIEF-VALVE/CONTROL-VALVE/INSTRUMENT categories do not fit generators, switchgear, and transformers. A new Module 3 row and revised unit-category set were added (skill version bumped to v2) — see `skills/bom-extraction/patternLog.md`. |
| Future-vs-current equipment convention | Throughout the one-line, elevation, and plan sheets, equipment reserved for a later phase but not part of this pre-purchase scope is drawn with a visibly lighter line weight and/or dashed outline, sometimes (but not always) with an explicit "(FUTURE)" or "FUTURE" text label (e.g. GEN-G6/NGR-G6 solidly confirmed "(FUTURE)" on Drawing E15's elevation; four VFDs at MVSWGR-E/F breakers 8/11/12/13 dashed with no "FUTURE" word on E08/E09 themselves, but their pump destinations are labelled "Future Finished Water Pump..."; the entire DC Battery System block dashed on Drawing E07 with no "FUTURE" text at all). | Every equipment item's future-vs-current status was confirmed by line weight **and** cross-checked against at least one other sheet before being included or excluded from this pack's findings — never inferred from a single sheet's styling alone. Only solid-line, unambiguously-current items were extracted as findings. |
| Existing equipment shown for context | Generators G1/G2 (1250kW), Main Switchgear (existing), Generator Parallel Switchgear (existing), TX-11/TX-12 (1500KVA), and an existing 2000KVA utility transformer are drawn in a grey/hatched style, distinct from both the solid (current-new) and dashed (future-new) conventions above. | Read as a third category — existing plant, not part of this new-equipment pre-purchase package at all — not confused with "future" (reserved capacity not yet built) or extracted as a current BOM line. The existing utility transformer and CoServ PMU-1 are explicitly marked for demolition (Key Note 1, Drawings E05/E07), confirming their existing (not new) status independently of the drawing style alone. |
| MVSWGR-E/F bus configuration stated two different ways across sheets | Drawing E07 states "MVSWGR-E 4160V, 3Ø, **4W**, 2000A, 50KA SCCR **TIN PLATED COPPER BUS**" for both MVSWGR-E and MVSWGR-F; Drawings E08 and E09 (each switchgear's own dedicated detail sheet) state "**3W**, 2000A **INSULATED COPPER BUS**, 50KA SCCR" for the same two pieces of equipment. Voltage, amperage, and SCCR agree across all three sheets; wire count and bus material/plating description do not. | Recorded as an open discrepancy in both `mvswgrE.md` and `mvswgrF.md`, confidence `UNSURE` for the wire-count/bus-material detail specifically (voltage/amperage/SCCR remain `SURE`, confirmed on 3 independent sheets each) — not silently resolved by picking one sheet over the other. See `skills/bom-extraction/patternLog.md`. |
| VFD tag numbering does not visibly match pump numbering one-for-one for future units | Drawing E08's own pump labels at MVSWGR-E breakers 11 and 13 read "Finished Water Pump P7" and "P8"; Drawing E15's elevation view of the same two breaker positions labels the VFDs themselves "VFD No.6" and "VFD No.7". The two current/real VFDs (breaker 5 → "VFD No.9"/"Pump P9"; MVSWGR-F breaker 6 → "VFD No.10"/"Pump P10") show no such discrepancy — their VFD number and pump number agree on every sheet reviewed. | Recorded as observed in `detection.md` and the twin (page007.md), not resolved. Does not affect this pack's findings, since the four future VFDs with the discrepancy are not extracted as findings in this pass regardless (see coverage below); if a future pass extracts them, this discrepancy must be resolved (or re-confirmed as a genuine dual-numbering scheme) before doing so, not silently picked. |
| Pump-number reuse between "(RELOCATED)" and "FUTURE" loads | Drawing E06 shows three existing 600HP-VFD-driven pumps labelled "Finished Water Pump 6/7/8 (RELOCATED)", while Drawing E05/E06 separately show 1200HP-VFD future stubs feeding "FUTURE Finished Water Pump 6/7/8" (pump numbers 6, 7, 8 reserved for a later, larger-capacity installation at the same numeric position). | Recorded as-is in the twin (`page005.md`) — not reconciled or assumed to be a drafting error, since a relocated existing pump and a future new pump sharing the same site-assigned number across a capacity upgrade is plausible without being a mistake. |
| Referenced sheet not included in this excerpt | Drawing EBFNE01, described on Drawing EBFNE02 (page 11) as carrying "the equipment tag table" and referenced twice by General/Key Notes for tag numbers and ground-wire routing continuation, is not among the 11 pages supplied. | Confirmed genuinely absent (checked every page's drawing number against EBFNE01, not found) rather than assumed out of scope without checking. Flagged here as a gap a future pass should close if EBFNE01 becomes available — not treated as this pack's own error. |
| Legend sheet is explicitly generic | Drawing GE01's own General Note: "THIS IS A STANDARD LEGEND. SOME SYMBOLS MAY NOT APPEAR ON THE DRAWINGS." | Every symbol/tag classification in this pack was confirmed against its actual appearance on a one-line/elevation/plan sheet, never assumed present just because the standard legend defines it. |
| "NGR" and "ATO" not spelled out in this set's own abbreviations table | Drawing GE02's abbreviations table (the analog of the P&ID's legend-derived tag grammar) does not include a row for "NGR" or "ATO", unlike SCCR ("SHORT CIRCUIT CURRENT RATING"), which is listed. | "NGR" (Neutral Grounding Resistor) is read directly from its own full spelled-out label on the one-line diagrams themselves (e.g. "NEUTRAL GROUNDING RESISTOR NGR-G3" on Drawing E10), not from the abbreviations table. "ATO" is never spelled out anywhere in this 11-page excerpt; per this skill's absence-policy and world-knowledge limits, its expansion is not supplied from outside the document — findings referencing it note this openly rather than asserting a definition. |
