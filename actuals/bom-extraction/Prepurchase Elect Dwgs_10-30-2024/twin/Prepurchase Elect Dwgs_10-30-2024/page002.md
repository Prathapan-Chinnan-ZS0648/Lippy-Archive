# Page 2 — Drawing GE02, "Legend and Symbols - II"

Continuation legend sheet: lighting-fixture symbols, lighting/distribution panelboard
symbols, receptacle types (GFI, WP, isolated ground), conduit/duct-bank line-type
symbols, homerun notation, switch-leg notation, a Communications Systems symbol block
(telephone/data/voice-data outlets, paging speakers), a Security Systems symbol block
(alarm panel, door switch, keypad, card reader, window switch, motion detector, CCTV
camera), a Fire Alarm Systems symbol block (control panel, smoke/heat detector, manual
pull, strobe/horn).

**Abbreviations table** (2 columns, ~90 entries) — includes, among many others: **SCCR =
"SHORT CIRCUIT CURRENT RATING"**, SWGR = "SWITCHGEAR", SWBD = "SWITCHBOARD", XFMR =
"TRANSFORMER", VFD = "VARIABLE FREQUENCY DRIVE", GEN = "GENERATOR", MCC = "MOTOR CONTROL
CENTER", MCP = "MOTOR CONTROL PANEL" or "MOTOR CIRCUIT PROTECTOR", ATS = "AUTOMATIC
TRANSFER SWITCH", MLO = "MAIN LUGS ONLY", OL/OLA = "OVERLOAD"/"OVERLOAD CONTROL RELAY".
"NGR" (neutral grounding resistor) does not appear as a row in this abbreviations table —
its expansion is only given directly on the one-line diagrams themselves (e.g. "NEUTRAL
GROUNDING RESISTOR NGR-G3" on Drawing E10) — see `detection.md`. "ATO" likewise does not
appear in this table or elsewhere spelled out in this set's legend sheets.
