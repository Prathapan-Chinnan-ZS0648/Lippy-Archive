16. Project Execution Methodology (D&B Phase)

Ltd. proposes to execute this project using a parallel-path methodology
wherein civil works, long-lead equipment procurement (pumps, clariflocculator mechanisms, filter
systems, chlorination equipment), rising main procurement, and detailed engineering proceed
concurrently from Day 1 of mobilization, in order to achieve the approximately 20-month Design-Build
schedule while managing interface risk through a dedicated Planning Engineer using a detailed Level-3
project schedule. Monthly progress review meetings will be held with GWSSB, supported by weekly
internal progress tracking.
