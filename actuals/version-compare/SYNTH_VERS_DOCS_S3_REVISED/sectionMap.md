# Section map

Maps each named section/unit to its twin file in each document, derived from each
document's own table of contents and confirmed against
`actuals/SYNTH_VERS_DOCS_S3_REVISED/twin/`. This document (`.docx`) carries no fixed
physical pagination in its underlying XML (unlike a rendered PDF), so the unit of
location is the document's own numbered section — the same unit its own table of
contents already uses — per `bootstrap.md` §12's "or whatever unit fits a format not
listed here."

before this map was finalized (the ToC's own listed page numbers were not used as the
unit of location, since a `.docx` does not fix page numbers the way a rendered PDF does).
