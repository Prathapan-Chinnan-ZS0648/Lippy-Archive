4. Operational Requirements

Point-of-sale (POS) integration with the University's existing CBORD student ID card system.

Online ordering and a mobile app for menu viewing, mobile ordering, and meal plan balance tracking.

Nutritional and allergen labeling for all menu items, updated each semester.

Compliance with all applicable state and local health department codes and inspection requirements.

At least one dedicated vegetarian/vegan station in each dining hall.

Dedicated catering event-management staff and online catering order portal for University departments. [NEW]
