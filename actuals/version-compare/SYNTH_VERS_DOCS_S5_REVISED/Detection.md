# Detection


| Quirk | Where observed | Handling |
|---|---|---|
| New document format: multi-slide presentation deck, not a paginated document or spreadsheet | Both decks are `.pptx` files with 11–12 slides each, not PDFs with pages or workbooks with sheets. | Per `skills/version-compare/Skill.md` Module 6 ("Mixed or converted formats"), normalized both decks to extracted per-slide text before applying grain and verdicts. Twin files use `Slide<NN><Title>.md` instead of `Page<NNN>.md` or `Sheet<Name>.md`, adapting `Bootstrap.md` §12's per-unit twin convention to this document type's actual unit of location (a slide). |
| A whole new slide added, with no counterpart at all | The source deck has a 7th-position slide, "EV Charging & Interconnection Requirements," entirely absent from the supporting deck (confirmed by listing every slide title in both decks, per `SectionMap.md`). | Judged as a slide-level ADDED unit: every bullet within the new slide is ADDED, consistent with skill Module 1's granularity-agnostic ADDED rule — the same rule already used for S4's whole-sheet addition, generalized to a slide. |
| Fourth occurrence of self-annotation, in a new concrete form | The new slide's own text explicitly states: "This slide is new in this revision — no equivalent content existed in the original briefing deck." Unlike S1/S2/S4's bracketed-tag convention (`[NEW]`, `[MODIFIED]`, `[UPDATED]`), this is a full-sentence prose self-annotation, not a tag. | Already promoted into skill Module 6 from S1 (plus explicit user generalization) and reconfirmed by S2 and S4. Used only as a cross-check pointer, per the existing rule — independently verified against `SectionMap.md`'s own slide-by-slide comparison (which confirms the slide has no counterpart), not accepted on the annotation's word alone. Logged in `PatternLog.md`: a fourth independent confirmation, and the first in prose-sentence form rather than a bracketed tag. |
| Slide renumbering after an insertion (all slides after the new one shift position by one) | Source slide 8 ("Eligibility Criteria") corresponds to supporting slide 7; every subsequent slide is likewise offset by one. | Mapped by slide **title/topic**, not slide number, per Module 2 stage MAP — the same row/ID-renumbering handling already generalized for tabular row IDs, applied here to slide position. |
| Agenda slide gained one new line item matching the new slide's title | The source deck's Agenda slide lists "EV Charging & Interconnection Requirements" as a 10th agenda line; the supporting deck's Agenda has 9 lines, no such entry. | Judged as one ADDED bullet within the Agenda slide's own findings — independent of the EV Charging slide's own ADDED verdict elsewhere; these are two different units (a table-of-contents-style reference line vs. the substantive slide it points to), matching the already-established "checklist line vs. requirement it certifies are distinct units" edge case, generalized here to "agenda line vs. the slide it references." |
| A table row gained an additional criterion alongside its existing rows | The Evaluation Criteria table gained a 6th row, "EV Charging Design — 10 points," with the other five rows' point values also changed (redistributed so the total still sums to 100). | Judged the new row ADDED, and every other row's own point value CHANGED independently — per Module 1's per-clause grain, redistribution across a table is not one aggregate "criteria changed" verdict but one verdict per row, exactly as skill v4/v5's column-granularity generalization already requires treating each cell/row as its own unit rather than summarizing structural change as a single note. |
| Personnel/contact change unrelated to scope change | The Questions & Contact slide's Issuing Officer, Title, Email, and Phone all changed (Derek Simmons, Director of Power Supply → Priya Patel, Senior Director of Power Supply & Grid Modernization), alongside the closing paragraph's wording update to mention EV charging. | Each of the four contact fields judged CHANGED independently (per Module 1's one-clause-one-verdict grain), distinct from the paragraph's own CHANGED verdict — no assumption that a title change implies the same reasoning as the paragraph's wording change. |
| A provision restated with an added qualifier, not replaced outright | The Commercial Terms slide's liquidated-damages bullet goes from "Liquidated damages apply for delays past the contractual COD." to "...at an increased daily rate reflecting the expanded scope." — the provision's core fact (LD applies) is unchanged, but a rate-related detail is added. | Judged CHANGED, not UNCHANGED — the added qualifying clause is new information about the same provision, so the sentence as a whole differs even though its central fact persists; this is a plain application of Module 1's "show both sides, quoted exactly" rule, not a new edge case. |
