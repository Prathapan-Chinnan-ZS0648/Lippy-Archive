# Ranking summary — bid-evaluation (10-document Tender Qualification batch)

## Why no ranking table

Every prior `RankingSummary*` report under this use case (ELECTRICAL, WATER_SCANNED,
SOLAR) covers multiple bidders competing for **one shared tender**, evaluated by **one
committee**, against **one shared supporting/base document** that actually functions as
that tender's eligibility criteria and evaluation record. This batch does not have that
shape:

- Each of the 10 source documents is a different company's own self-declared Tender
  Qualification & Eligibility submission for its **own, distinct tender reference**
  (10 different tenders across Kerala, Karnataka, Jharkhand, Himachal Pradesh, Rajasthan,
  Tamil Nadu, Punjab, Uttarakhand, Gujarat, and Madhya Pradesh — see each document's own
  manifest.md section for its tender reference).
- The shared supporting document (`Tender_Qualification_Document_ILLUSTRATIVE_SAMPLE.pdf`)
  is itself a self-declared qualification profile for an **eleventh, also-unrelated**
  company and tender ("Ganges Infrabuild Private Limited," PWD/RB/2026-27/NH-118/0042) —
  it is not a scoring or eligibility-criteria document.
- **None of the 10 documents, nor the supporting document, contains an Evaluation
  Committee determination, an awarded technical score, or an eligibility finding
  anywhere.**

Per `skills/bid-evaluation/skill.md`'s absence-policy, every one of the 10 bidders is
**NOT ADDRESSED** and **not ranked** — see each bidder's own findings file
(`findings/bid-evaluation/<document-name>/score.md`, `eligibility.md`, `price.md`, `deviations.md`, `basis.md` — plus informational fields such as `companyProfile.md`, `financialStanding.md`, per skill.md v5) for the individually-verified basis.
A ranking table would be meaningless here regardless of the absence outcome, since there
is no shared tender or committee for a ranking to compare bidders *within*.
