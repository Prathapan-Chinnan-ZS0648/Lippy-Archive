## 1. Introduction & Background

The Cascadia Department of Transportation ("CDOT" or "the Department") operates and maintains a statewide Intelligent Transportation System (ITS) network spanning approximately 1,464 centerline miles of interstate and state highways, following the February 2027 opening of the SR-509 Port Neelan Extension. The network now includes 660 closed-circuit television (CCTV) cameras, 355 dynamic message signs (DMS), and 196 ramp metering locations, all connected to a Traffic Management Center (TMC) located in Cascadia City.

CDOT's current Advanced Traffic Management System (ATMS) software platform was deployed in 2011. The platform vendor has announced that extended support will end in 2027, and the platform no longer supports modern integrations, AI-based incident detection, or current cybersecurity standards. Following a December 2025 statewide cybersecurity assessment that identified critical vulnerabilities in ITS field device communications, CDOT is reissuing this Request for Proposal (RFP) to solicit qualified vendors to modernize its ATMS platform, refresh field device hardware across the network, upgrade the communications backbone connecting field devices to the TMC, and implement enhanced cybersecurity resilience measures.

This program will be delivered in three phases: a Pilot Corridor phase, a Regional Rollout phase, and a Statewide Rollout phase, as described in Section 9 (Project Timeline).

## 2. Definitions

| Term | Definition |
| --- | --- |
| ITS | Intelligent Transportation System — the combined field devices, communications network, and software used to monitor and manage highway traffic. |
| ATMS | Advanced Traffic Management System — the central software platform used by TMC operators to monitor and control field devices. |
| TMC | Traffic Management Center — CDOT's central facility for statewide traffic monitoring and incident response. |
| DMS | Dynamic Message Sign — an electronic roadside sign used to display traveler information and alerts. |
| CCTV | Closed-Circuit Television — roadside cameras used for traffic monitoring and incident verification. |
| Ramp Meter | A traffic signal on a freeway on-ramp used to regulate the rate of vehicles entering the freeway. |
| 511 System | CDOT's statewide traveler information phone and web service. |
| NIST | National Institute of Standards and Technology — issuer of the cybersecurity framework referenced in this RFP. |
| SLA | Service Level Agreement — a contractually defined performance commitment. |
| MP | Mile Post — the reference marker system used to identify highway locations. |
| SOC | Security Operations Center — the 24/7 monitoring function required under this revision. [NEW] |

## 3. Project Objectives

- Replace the legacy ATMS platform with a modern, standards-based ITS software platform.
- Refresh field device hardware (CCTV, DMS, ramp meters) that has reached or is approaching end of life.
